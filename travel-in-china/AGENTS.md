# 中国旅行图志

新增城市、修改城市内容或扩展地图交互前，先阅读 [城市制作指南](PRODUCTION_GUIDE.md)。统一要求、制作经验与验收规则在该指南维护；当前运行方式和实现状态见 [README.md](README.md)。成都是范例，不能将成都专属假设直接复制为其它城市的事实。

媒体遵守根目录 AGENTS.md：图片、音频等上传 Cloudflare R2，网页引用云端地址，不提交媒体文件。本地缓存必须被 Git 忽略。

按省级地区逐个详做，先列省内代表性城市／地区／景点／人物的覆盖目录，再逐项制作；不能把几篇省级样章或单个省会当成全省完成。当前顺序先云南，昆明起步；四川不能只限成都，重庆作为独立直辖市专题。完整范围和验收标准见 PRODUCTION_GUIDE.md 第 0 节。
