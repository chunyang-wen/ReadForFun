# 中国传统建筑艺术展卷

制作或修改本目录中的建筑展卷前，阅读 `PRODUCTION_GUIDE.md`；处理佛光寺东大殿时，再阅读 `MODEL_NOTES.md`。用户当前指示优先于这些默认规范。

启动后续卷前，阅读 `SERIES_PLAN.md`：本系列按十卷收束，第 7—10 卷补足门、民居雕刻、园林户牖和台基石作。卷目规划不等于已完成，报告进度时区分新增卷与未交付卷。

- 后续卷默认聚焦一座主建筑，从原书章节与可靠建筑资料建立证据，再制作可交互三维构造。
- 记录原书版本、页码与图号；未取得或未核对的书页不能写成已引用。
- 区分文献明确、图像判读、比例推定和待核定参数。第一卷的转角、补间、内槽与隐蔽节点简化不能当作通用实测模板。
- 优先核对柱网、支承、方向与节点，再增加纹理、椽瓦等细节。不要用几何件数证明精度。
- 复用查看器能力；按建筑重建几何。维护既有卷地址和卷内建模记录。
- 交付前检查关键剖面、最大拆解、构件拾取与移动端；对新发现的结构问题增加有意义的回归检查。

现有模型检查：`node --test chinese-architecture/tests/model.test.js`（从仓库根目录执行）。文档改动只需相应的文档检查。
