# 佛光寺东大殿：三维构造研究模型

后续展卷的通用要求见 [美轮美奂系列制作规范](PRODUCTION_GUIDE.md)；本记录保留第一卷的具体实现与精度边界。

本页集中研究一座建筑，以可旋转的三维几何替代此前的二维立面示意。它是公开资料支持下的构造研究模型，不是由点云或完整测绘图纸直接重建的数字孪生。

## 资料

1. [张荣：佛光寺东大殿建筑数字化勘察与唐代材分研究](https://www.kaah.or.kr/download/mailing/kaah_seminar_presentation1_1.pdf)：PDF 第 16–18 页的结构与铺作图、第 26–28 页的材分统计。代码注释中标明推定参数。
2. [香港大学收录的梁思成测绘图资料页](https://learning.hku.hk/ccch9051/group-13/items/show/1)：柱网数量、七间四进与图纸元数据。
3. [East Main Hall seismic vulnerability study](https://www.mdpi.com/2673-4117/7/5/200)：第 3.1 节的柱网总体尺寸与图 5。工程分析模型本身也有简化，不能当作构件详图。
4. [UNESCO：五台山](https://whc.unesco.org/en/list/1279/)：遗产背景。

没有复制或再发布上述资料中的照片、测绘图或扫描件。网页模型和构件解释为原创实现。

## 尺度与坐标

- 单位：米；Y 向上；Z 正向为西侧前檐；X 为面阔方向，正向指北。
- 柱网宽 34.00 m，深 17.66 m。屋面外挑不计入该柱网尺寸。
- 沿面阔七间：4.40 / 5.04 / 5.04 / 5.04 / 5.04 / 5.04 / 4.40 m。
- 柱位集合严格区分外圈 22 根与内圈 14 根，没有把规则矩形网格的每个交点都放上柱。
- 进深四段在模型中等分为 4.415 m，内柱的进深位置属于规则化重建，不是逐柱测绘坐标。
- 材厚、华栱出跳与下昂角度参照勘察数据。代码使用第一跳 0.5434 m、第二跳 0.4490 m；第三、四跳按合计值 0.9804 m 等分。后两跳的等分是模型假设。
- 柱高、卷杀、侧脚、梁架与屋面标高、梁截面、台基、瓦片和门窗尺寸均为比例近似。柱子保留轻微卷杀轮廓，目前没有逐柱侧脚与生起复原。

## 几何组织

`model.js` 按 11 个构造层生成模型：石作、柱网、阑额、铺作、明栿、平闇、草架、槫檩、椽架、屋面和围护。每件可点选几何附带独立编号、类别、构造层及可用的位置备注。

- 柱础分出底座和柱脚承托面，柱身为旋转体。
- 柱头铺作分出栌斗、泥道栱、两跳华栱、小斗、两道下昂、令栱、替木等。局部视图保留下昂后尾。
- 斗以斜欹、底部、槽口肩部建模。槽口仅解释相交方向，尚未复原原构件的全部卯口、暗榫、销键和不规则加工痕迹。
- 第一跳华栱的外端不加横栱，区别于每跳都塞满横栱的通用堆叠模型。
- 梁架区分明乳栿、四椽栿、侧向丁栿和上部草架；脊下有独立叉手。
- 四阿屋顶由四片坡面、沿坡椽、转角角梁、各道槫、瓦垄和屋脊组成。山面与长坡面的椽方向不同。
- 瓦片、椽段等采用实例化绘制。界面显示的是模型几何件数，**不是实物历史构件数量**；一根弯曲椽也可能分成多个几何段。
- 13,000 多件几何中多数是瓦垄与椽段。模型精度不能由这个数字衡量。

## 必须保留的精度边界

1. **转角铺作**：目前由正交与角向分支表达出挑方向，共用柱位，未解决真实角昂、华栱和梁枋的全部穿插互锁。这是全模型最重要的待核定节点。
2. **内槽与补间铺作**：区别于外檐柱头，但逐攒变化、完整斗槽和垫木尚未复原；间隔采用规则化安排。
3. **上部梁架**：分清明栿、平闇和草架层次，所有标高和搭接仍需与完整纵横剖面逐项校准。端部叉手不越过脊槫范围。
4. **隐蔽榫卯**：没有用凭空猜测的复杂榫头充当文物事实。模型中的明示斗槽是教学配合，普通梁柱端头没有虚构完整加工细节。
5. **屋面与围护**：没有推定唐代原始彩画、瓦件年代或门窗时代；材质和轮廓是视觉近似。
6. **剖切与拆解**：剖切为实时裁切，不生成真实锯切实体封口；分层展开是观察工具，不是拆卸施工方案或受力模拟。

达到测绘级复原仍需：授权的完整柱网坐标和标高表、各架梁栿测绘、每类柱头/补间/转角铺作详图、隐蔽节点记录，以及古建筑专业人员逐节点校核。

## 交互与检查

- 六个观察步骤；斜观、前檐、山面、俯视；单指/鼠标旋转、滚轮/双指缩放、平移。
- 全殿分层与单攒铺作局部拆合；双向可移动剖切；逐层可见性；构造分色；点选构件解释。
- 视口获得焦点后，方向键旋转，`+` / `-` 缩放，`0` 恢复视角，`Escape` 取消选中。
- `node --test chinese-architecture/tests/model.test.js` 检查柱网拓扑、构件类型、变换有效性、模型边界及关键梁架/铺作数量。
- 浏览器验证全景、局部、剖切、分层、构件拾取、移动端和无控制台错误。
