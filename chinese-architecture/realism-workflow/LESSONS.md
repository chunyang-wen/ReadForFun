# 从教学模型走向可信复原：可迁移经验

2026-10-15，来自太和殿与北京太庙前殿的实际实现、失败尝试及浏览器检查。适用于建筑、工业产品、博物馆展件及其他参考驱动的三维项目。方法可以迁移，具体对象的尺寸、结构、装饰、材料和结论必须重建证据。

## 后续卷如何采用这些经验

这些经验已纳入 [制作规范第12—13节](../PRODUCTION_GUIDE.md#12-外观真实性的迭代和重放)、[真实性工作流](README.md) 和 [图录接入清单](../photos/README.md#其他卷接入清单)。新建或更新任何建筑卷时，先列出本卷需要修正的结构/外观问题与应补充的照片，再按“基线与证据 → 局部修正 → 多方向/全长/归属检查 → 材质与光照 → 图录联动 → 共同验收”执行。

模型改进、配图覆盖和软件运行分别记录结论。可先完成有据部分，未核节点与缺图保留待办；不把太和殿、太庙的数量、尺寸、纹样、拟合结果或通过记录迁移成另一卷的事实。以下保留具体经验与失败原因，操作入口以制作规范和共享组件说明为准。

## 先定义“真实”要检查什么

把验收分成四条线，分别报告：

|维度|要回答的问题|有效证据|常见误判|
|---|---|---|---|
|历史与身份|这是哪个对象、哪个时期？|原始图档、维修记录、可定位的现场照片|同类物、不同年代的部件拼成一个“真实”对象|
|空间与构造|部件实际接在何处？|测绘、剖面、支承与节点记录|数量吻合、端点贴住或动画顺畅就认定结构准确|
|外观|从多机位、换光后仍接近参考吗？|轮廓、比例、材质、纹样逐项对应|细节多、反光强或截图好看就称照片级复原|
|软件|能稳定加载、拆解、选择和重放吗？|自动测试、真实UI操作、日志、截图|软件通过替代前三项真实性认证|

目标没有证据支持时，保持“推定”身份；不要补造一个精确值来满足软件检查。

## 一轮可执行的工作顺序

1. **保留状态**：读项目规则和已有未决项，记录Git状态。复制本轮将改的源文件、配置和原始证据报告，计算SHA-256；不清理别人的工作。
2. **登记证据**：每个来源写对象、年代、定位、等级、用途、版权及局限。区分原始资料、作者描述、转载、搜索线索；标题相似不证明模型就是目标。
3. **先校观察条件**：固定机位和视口，对齐轮廓控制点。画面中不一致的部分可能来自透视、裁切、光照或遮挡，先排除这些变量。
4. **按收益选改动**：先体量、支承、缺失轮廓和连接，再表面材质与细纹。局部试件验证后，检查扩展到整个表面是否出现新的坡向、交界或性能问题。
5. **建立对照**：基线、材料、几何、组合条件分别保留；逐件色差、天空和曝光也算变量。同一轮对比须使用同一相机，不把多变量改动说成单变量因果。
6. **检查实际几何**：顶点、法线、朝向、搭接、支承、ID、变换与边界都检查。用换光、剖切、背面和斜视找正面看不到的问题。
7. **重放真实操作**：在实际渲染页面操作可见控件，保存运行状态、错误日志和原始截图。设备尺寸以页面实际innerWidth/innerHeight为准。
8. **写出结论和下一证据**：保留有效改动，也保留被拒绝的候选、失败原因和回退方法。明确尚未取得什么资料，不以“已测试”结束研究。

## 本轮遇到的问题及复用办法

|实际问题|根因与修正|以后怎样预防|
|看图觉得屋顶过高，拟合却没有通过|不同机位与推定柱网耦合；太庙相机残差约15px，高于手工标点约4px，形状参数触边，候选未采用|先拟合相机，保留独立视角；残差、参数触边与验证缺失共同决定是否接受，不能只挑变小的误差|
|增加局部瓦片后，样片像贴在旧模型上的补丁|全屋面仍是稀疏连续圆条|局部验证成功后扩展连续表面，单独处理前后坡、山坡、下檐环带与脊线|
|前坡可用的瓦片直接旋转到其他坡后方向错乱|模型局部坐标、法线、沿坡轴混淆|每面明确cross/run/up基，检验沿坡轴向外、法线向上，检查变换后的顶点|
|筒瓦存在却看起来像扁平条纹|盖瓦顶面三角绕序与板瓦相反，表面法线倒置|分别测试顶面法线；DoubleSide不能替代正确绕序与法线，必须换光目视|
|椽尾补了可见部分，却悬在外侧|只从檐口向里延伸固定长度，没有追踪支承|先定位连续檩圈，再生成实际跨度；上檐和下檐、前坡和山坡分别求支点|
|椽尾标高正确，角部却跨出檩端|一维标高检查漏掉有限支承的横向范围|检查完整支承面；角部采用有明确推定身份的收束/扇形布置，不只检查某一坐标|
|椽端没问题，椽身中段穿屋面|用一根直线贴合凸曲线，端点检查不能发现中部穿透|沿全长采样圆柱包络；太庙以两段直件示意并检查连续，不把未核榫接说成实物做法|
|增加新椽尾后与旧椽重复穿插|实例批次混合多种构件，直接叠加造型|精确分离替换区，保留原records和每个矩阵，逐项确认未误删柱梁|
|抬起屋面时，新椽尾也跟着走|按生成函数分组，而非构造归属分组|生成器分别返回覆盖层和支承层；验证位移归属，不能只看最终画面|
|点中构件后，拆解时选中框或坐标不动|ID、实例变换与父级世界变换脱节|保留稳定ID与实例索引；每帧用实例矩阵乘父级matrixWorld更新坐标和选中框|
|工具说已设手机视口，实际仍是桌面|视口override未生效|读取真实尺寸并使检查失败；必要时用固定同源iframe验证布局，同时明确不是设备仿真|
|截完图才改代码，报告仍引用旧hash|验证、截图和文档没有形成版本链|改受检源码后重验；报告关联源码hash、配置hash、截图和状态，不能手改通过记录|

## 拟合与量化的接受条件

`evidence-fit.js` 提供无建筑参数的有界搜索和拒绝规则，供不同项目建立自己的目标函数。它不是摄影测量软件，也不能自动识别错误标点、畸变或来源身份。

- 控制点的真实三维坐标与二维识别都需要证据，不能用任意柱网给自己“标定”。记录手工定位误差。
- 同时优化太多几何和相机变量会互相补偿。先固定有据变量，做敏感性分析，再引入新自由度。
- 最优值贴住边界是诊断信号，不代表实物恰好等于边界。检查参数范围、对应点和模型假设。
- 拟合误差下降只能支持该目标函数下的比较。要保留未参与拟合的点或第二视角；不能换算成“还原度百分比”。

## 从局部扩到整件时必须重新检查

1. 所有方向的边界、脊缝和转角，不能只把一个局部反复实例化。
2. 几何和材料要分开归属。涂层附在载体上，不能为好看而漂浮；木构、覆盖层和附属装饰的拆解归属也不同。
3. 新增支承是否真的接到上游构件，旧支承是否重复；剖开覆盖层后能否追踪到柱、梁或基础。
4. 远处整体轮廓、近处细部和手机取景均重新检查。三角形、实例批次与显存是软件开销指标，不能用来证明精度。
5. 材质使用中性的可解释光照；程序噪声不得被称为实测风化，照片阴影不得烘焙成永久底色。

## 留给下一项目的最小包

- 对象和历史阶段说明；原书/规格书/测绘的版本、页图与未核项。
- 证据清单：id、URL、本地合法资产路径、等级、范围、许可、局限。
- 参数清单：单位、坐标、基准、来源、推定范围，避免多位小数制造假精度。
- 构件清单：稳定ID、位置、朝向、所属层、材料、上游支承及证据。
- 条件配置：变量、固定相机与真实视口、剖切/拆解/换光/拾取用例。
- 历史快照、源码校验、原始测试输出、状态JSON、原图截图和失败尝试。
- 一份结论：哪些有改进，哪些无效，下一轮什么证据最能改变判断。

太庙的 `roof-system.js` 是特定对象的适配器；不要把其.32m瓦距、原柱网、灰背/椽尾推定或染色应用到其他对象。迁移接口、证据方法和测试，不迁移建筑结论。


## 实景照片与模型并读（2026-10-15）

新增可复用的[建筑实景图录](../photos/README.md)，先在太和殿和太庙前殿验证。模型负责揭示空间与构造关系，高清实景负责补充尚未复原的纹样、材质和装饰。照片与本建筑章节绑定；公开原片、缩略与展示尺寸分开；原始哈希、日期、作者、许可、改动说明和模型证据边界随图保留。

存储上传成功、公开域名可读、浏览器成功解码是三项不同检查。本轮 R2 读回校验通过，公开域名在当前网络为 403，所以随页面保留高清 WebP 备用。不能把备用图成功显示写成 CDN 已恢复。所有可见照片仍只是某一时点的表面证据，不能据此补造隐藏榫接或历史颜料。


### 多角度图录的第二轮经验

- 同一地点分类里的图片不一定是同一殿。太庙候选中有作者明写 Back Hall 的后殿，也有单檐建筑；不能为了补齐“侧面”误配给重檐前殿。
- 罗盘方向取自明确的原作者说明；未知方位保留“斜向”，不从阴影或画面左右猜东、西。太和殿已取得正面、东南、西南、西北和北侧照片；太庙前殿的纯侧面、背面仍保留缺口。
- 同一模型步骤可以对应多张照片。返回同一步模型时保留当前选图；屋角照片还应进入转角局部，不能只回到通用柱头节点。
- 缩略图改为多行，正文与高清弹层均提供前后浏览；手机查看多张图不必反复滚回缩略图。
- 等比缩小也要检查色彩配置。太庙2023年原片嵌有 Adobe RGB，WebP 应保留 ICC；原片字节、来源 SHA1 与最终 SHA256 分别记录，不做生成式增细或改色。
- 仓库全局忽略 WebP 时，本地备用图可能只在当前机器有效。本轮为图录备用目录增加限定的忽略规则例外，确保静态页面交付能带上授权图片。
- 来源站返回 429 时遵守 Retry-After；本轮收到600秒要求，等待后降低下载频率。限流失败不能写成原片已取得。
- 浏览器缓存可能让新照片配上旧模型事件逻辑。本轮发现外层重载没有更新内层脚本，须检查实际 script src 与节点选值；复放窗口使用明确版本，不凭刷新动作认定已加载新源码。
